# Kasane

(Kasane is the Japanese word for layering) (Japanese theme just for vibes)

This is heavily inspired by [SPLOOB by mors and Catonator](https://mors-games.itch.io/sploob) so you should go and play that, and then also you should probably marvel at my [hypocrisy](https://redfloatplane.lol/blog/17-why-share).

The basic thought here was: I love games where things synergise and have some emergent properties. I love games where you get to pick things every few minutes. I love score attack games!

This is the first game I built in about a year, and the difference between the stuff I built with Opus 4.5 a year ago and what I can build now with Opus 5.5 is absolutely mind-blowing. I truly have not looked at a single line of the code for this game, which very much was not the case for last year's games. In fact I don't even know the stack. I could really, genuinely just describe the game I wanted, the gameplay I was looking for, suggest tweaks, and basically be the director of the game.

What a time to be alive. I had so much fun making this.

## Controls

- Arrow keys
- P to Pause

Also works on mobile.

I used to end each of these with "**All these games are incomplete and broken.**" but I don't actually know that that's the case anymore. Wow. The future moves _fast_.
